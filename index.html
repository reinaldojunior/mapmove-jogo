Como jogar
  • Analógico (esquerda): arraste para cima para acelerar até 6:30/km; solte e ele volta a 7:30/km. Arraste para os lados para virar.
  • Botão (direita): para cima pula, para baixo abaixa (galhos), para os lados pega água no ponto de hidratação.
  • Na calçada você perde velocidade. Passou dela, leva penalidade: 3 penalidades desclassificam.
  • Teclado: ← → viram, ↑ acelera, espaço pula, ↓ abaixa, E pega água.
